# Tasks and records, claim by claim

Generated by `tools/claims.py tables`; do not edit. For every claim of [CLAIMS.md](../CLAIMS.md) that has tasks: each task with the batches that contain it, its predicted value, and the latest record of the task in [records/](../records/), if there is one. A task without a record reads "not re-run": nothing in this repository then says what it computes to. A record reads "stale" when its task has changed since it was computed (another surface, another object, another predicted value): it supports nothing until the task is run again.

A predicted value comes from the package or, for the realized twists, from the batch file. "Computed" is what the task found; the status is `ok` when the two agree, or when nothing is predicted and the task gave a value. A record names the day it was computed, the commit of the code and the wall time. Tasks of the dependent batches share ids: the Batches column says which computation a row is.
